 💱 Currency Converter

A sleek, real-time currency converter web application that uses live exchange rates to convert between different currencies instantly. 

**The best part?** No API key is required! Just download and run.

---

## ✨ Features

- ✅ **No API Key Required** – Works out of the box.
- ✅ **Live Exchange Rates** – Fetches real-time data from public APIs.
- ✅ **30+ Currencies** – Supports all major world currencies (USD, EUR, GBP, LKR, INR, etc.).
- ✅ **Swap Functionality** – Instantly swap the "From" and "To" currencies with one click.
- ✅ **Auto-Convert** – Results update automatically as you type the amount.
- ✅ **Fully Responsive** – Optimized for desktop, tablet, and mobile devices.
- ✅ **Fallback API** – Automatically switches to a backup API if the primary one fails.

---

## 🛠 Tech Stack

- **HTML5** – Structure
- **CSS3** – Modern UI with Dark Theme and smooth animations
- **Vanilla JavaScript (ES6+)** – Logic and API calls
- **Fetch API** – Asynchronous data fetching

---

## 📦 APIs Used

This project uses free, open APIs that do **not** require an API key.

1. **Primary:** [irfanokr/currency-api](https://www.npmjs.com/package/@irfanokr/currency-api)  
   *(Supports 170+ currencies, daily updates)*

2. **Fallback:** [Frankfurter API](https://www.frankfurter.app/)  
   *(Activates automatically if the primary source is unavailable)*
